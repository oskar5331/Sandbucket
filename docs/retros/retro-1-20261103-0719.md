## Misses & mistakes

- **Unit C's design rested on a wrong assumption:** that CORS needs a signed S3 call. Checking the API spec caught it before any code was written.
- **The dev `GARAGE_RPC_SECRET` was 66 characters instead of 64.** Caught by a length check, not on sight.
- **The setup script retried a refused token for 60 s with a misleading error.** The fake-API rehearsal found it.
- **The dbmate rehearsal was itself broken twice:** first `$OUT` not expanding inside a single-quoted script, then a substitution that also rewrote the download URL. Both times the cause was traced before the Dockerfile got the blame.
- **The plan assumed Chromium would run** without extra packages. It didn't.

- **Compose resolving relative paths against the first file** (the repo root) is from memory. If wrong, `.devcontainer` and `.` in the override point to the wrong place.
- **The Garage setup has only been tested against a hand-written fake.** CORS rule field names and `ImportKey` behaviour are unconfirmed against a real Garage.
- **The dbmate checksums are trust-on-first-use**, computed from a single download.
- **CI has never run.**
